# Lista de equipo

Formulario web para armar la lista de jugadores de un pedido de ropa deportiva personalizada (camisetas y conjuntos, varón y dama).

Descarga la lista en **Excel**, **PDF** (con foto de referencia incluida) o **CSV**.

## Cómo usarlo

1. Escribe el equipo o cliente y las telas.
2. Agrega cada jugador: nombre, talla, número, género, prenda y manga.
3. Descarga el archivo con los botones de abajo.

No necesita instalación ni servidor: es un solo archivo, `index.html`. Los datos se quedan en tu navegador.
